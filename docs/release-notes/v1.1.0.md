**ocr 1.1.0: olmOCR removed.** Start with [docs/TESTERS.md](https://github.com/pkeenan87/ocr/blob/v1.1.0/docs/TESTERS.md).

**Removed: olmOCR.** On the 61-page holdout it found 191 of 292 values, against 206 for dots-ocr and 271 for paddleocr-vl, and it was the slowest, at 20 s/page on Linux (see [docs/model-lineup-eval.md](https://github.com/pkeenan87/ocr/blob/v1.1.0/docs/model-lineup-eval.md)). Use `dots-ocr` for layout, transcripts and tables, and `paddleocr-vl` as the fast default.

**Upgrading**
- `ocr server setup` prints a one-time notice saying where the old olmOCR weights are and that they can be deleted. It also drops the `olmocr` entry from your config.
- A running olmocr server can still be stopped with `ocr server stop`.
- Checkpoints made with olmOCR are discarded and the file is scanned again.
- `--model olmocr` now fails with an error and a hint to use `dots-ocr`.
- The `ocr` version is part of each output's `scan_record`. In directory mode, outputs made by an earlier version are rescanned once.

**Download**
- **Linux x86-64:** `ocr-1.1.0-linux-x86_64.tar.gz` contains:
  - the `ocr` binary (glibc 2.35 or later: Ubuntu 22.04, Debian 12, Fedora 36 and newer);
  - the Claude skill (`skills/ocr`);
  - the README and the tester guide;
  - the license and THIRD_PARTY_NOTICES.md.

  Check it with the `.sha256` file beside it.
- **Mac:** build 1.1.0 from source. The Mac build was checked by hand, not by CI.
- **Windows:** still a preview, not yet run on a real machine.

**Getting started on Linux:**

    sha256sum -c ocr-1.1.0-linux-x86_64.tar.gz.sha256
    tar xzf ocr-1.1.0-linux-x86_64.tar.gz
    sudo cp ocr-1.1.0-linux-x86_64/ocr /usr/local/bin/
    ocr server setup --model dots-ocr
    ocr server start --model dots-ocr
    ocr scan --model dots-ocr --input-file filing.pdf

Setup picks the CUDA, Vulkan or CPU build of llama.cpp for your hardware, and downloads it with pdfium and the model weights. Every file is checked against a pinned sha256.
